# Research Protocol

1. Register a hypothesis before touching holdout data.
2. Pin source manifests and data hashes.
3. Use chronological dev and validation partitions.
4. Keep a sealed final holdout inaccessible to ordinary optimization commands.
5. Version all execution assumptions.
6. Require cost/slippage stress, parameter perturbation, and regime analysis.
7. Prefer walk-forward over repeated optimization on expanding history.
8. Record every experiment configuration and result artifact.
9. Promote a strategy only when evidence survives independent validation.
10. Never infer queue priority from MBP/L2 when order-level evidence is unavailable.
